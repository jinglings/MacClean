Using MacClean

MacClean moves the files it cleans to the Trash, and you can restore them from Cleanup History. These actions can’t be undone from Cleanup History, so read the in-app notes before running them: emptying the Trash, deleting Time Machine local snapshots and the other Maintenance commands. After the Trash is emptied, a file can only be recovered with Recover Files if it still exists in a local snapshot or Time Machine backup.
